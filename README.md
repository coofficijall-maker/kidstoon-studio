# KidsToon Studio (Termux Edition)
Automatizirani Python engine za produkciju 2D edukativnih animiranih crtaća u Full HD (1080p) rezoluciji direktno iz Termux okruženja.

## Funkcionalnosti
- **1080p 30FPS Render:** Visoka oštrina slike prilagođena za YouTube i mobilne uređaje.
- **Dinamička animacija:** Glatko kretanje likova po sceni uz simulaciju skakutanja.
- **Automatski titlovi:** Generisanje čitljivih titlova s crnim obrubom za najmlađe gledaoce.
- **Audio produkcija:** Automatska glasovna naracija (TTS) spojena s generisanom pozadinskom melodijom bez autorskih prava.

## Instalacija i pokretanje
```bash
git clone git@github.com:coofficijall-maker/kidstoon-studio.git
cd kidstoon-studio
python -m venv env
source env/bin/activate
pip install -r requirements.txt
python studio.py
```
